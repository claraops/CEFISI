# Code de conduite

## Notre engagement

Dans le cadre de ce projet de Master 1, nous nous engageons à faire de la participation au dépôt une expérience respectueuse pour toutes et tous, indépendamment du niveau, du parcours ou de l'identité.

## Comportements attendus

- Respecter les personnes et les points de vue ; discuter des idées, pas des individus.
- Accepter les retours de revue de code avec bienveillance et y répondre dans les délais raisonnables.
- Utiliser un langage clair, inclusif et professionnel dans les issues, PR et commits.
- Aider les membres qui démarrent ; documentation et explications valent mieux que les raccourcis silencieux.
- Signaler tout problème de sécurité ou de confidentialité rapidement.

## Comportements inacceptables

- Propos sexistes, racistes, discriminatoires ou harcelants.
- Publication de données personnelles ou de documents CEFISI non autorisés.
- Pressure abusive pour faire merger du code non vérifié.
- Usurpation d'identité ou contournement des revues.

## Signalement

Signalez tout incident à l'équipe via une issue privée ou directement au responsable du dépôt [@claraops](https://github.com/claraops). Les signalements sont traités confidentiellement ; des mesures proportionnées (suppression de contenu, blocage temporaire) peuvent être prises.

> Ce code s'applique à tous les espaces du dépôt : issues, PR, commits, discussions et documentation.
